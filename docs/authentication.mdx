---
title: "Authentication"
description: "Authenticate REST and MCP requests with a NextFlow API key."
---

Create a key in **Settings > API Keys** after signing in to the application. Copy it when it is displayed and keep it in your server environment. Key management requires Unkey to be configured by the application operator.

Set `NEXTFLOW_ORIGIN` to your application origin (for example, `http://localhost:3000`) and `NEXTFLOW_API_KEY` to your key:

```bash
curl "$NEXTFLOW_ORIGIN/api/v1/workflows" \
  -H "Authorization: Bearer $NEXTFLOW_API_KEY"
```

REST endpoints under `/api/v1` and MCP at `/api/mcp` require the bearer key. The generated OpenAPI document at `/api/v1/openapi.json` is public. The browser editor uses Clerk sessions.

Keys act on behalf of their owner. Never put them in client-side code, URLs, or source control. Revoke a compromised key from **Settings > API Keys** and update any integrations using it.
