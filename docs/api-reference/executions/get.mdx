---
title: "Get Execution"
openapi: "GET /v1/executions/{id}"
description: "Poll or retrieve the status of a specific workflow execution run."
---

## Authentication

Requires a Bearer token.

## Path Parameters

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `id`      | string| Yes      | The `runId` returned from an execute endpoint. |

### Example Request

```bash
curl -X GET "https://next-flow-beta.vercel.app/api/v1/executions/123-execution-run-id" \
  -H "Authorization: Bearer nf_YOUR_API_KEY"
```

## Response

Returns the execution status (`PENDING`, `RUNNING`, `COMPLETED`, `FAILED`) and details of each inner `nodeRun`.

```json
{
  "id": "123-execution-run-id",
  "status": "COMPLETED",
  "scope": "FULL",
  "nodeRuns": [
    {
      "nodeId": "node_1",
      "status": "COMPLETED",
      "output": { "url": "..." }
    }
  ],
  "durationMs": 4500
}
```
