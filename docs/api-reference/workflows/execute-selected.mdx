---
title: "Execute Selected Nodes"
openapi: "POST /v1/workflows/{id}/execute-selected"
---

Runs the requested nodes and their upstream dependencies from the saved workflow. Supply internal IDs from `GET /api/v1/workflows/{id}`:

```json
{
  "idempotencyKey": "selected-001",
  "selectedNodeIds": ["YOUR_TARGET_NODE_ID"]
}
```

The response uses scope `SINGLE` for one selected node or `PARTIAL` for several, and includes the number of nodes admitted with their dependencies. Either scope can finish with status `SUCCESS` when every admitted node succeeds.

The `inputs`, `variables`, `idempotencyKey`, and `webhook` fields follow the same contract and limitations as [full workflow execution](/api-reference/workflows/execute). Selected runs resolve fresh upstream inputs; they do not treat old canvas previews as successful dependencies.
