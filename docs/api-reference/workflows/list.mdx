---
title: "List Workflows"
openapi: "GET /v1/workflows"
description: "Get a list of all your saved workflows across the platform."
---

## Authentication

Requires a Bearer token in the `Authorization` header.

## Request

This endpoint takes no parameters.

## Response

Returns an array of workflow objects containing their identifiers and basic metadata.

```json
{
  "workflows": [
    {
      "id": "123e4567-e89b-12d3-a456-426614174000",
      "name": "My Creative Pipeline",
      "updatedAt": "2024-04-14T10:00:00.000Z"
    }
  ]
}
```

### Example Usage

```bash
curl -X GET "https://next-flow-beta.vercel.app/api/v1/workflows" \
  -H "Authorization: Bearer nf_YOUR_API_KEY"
```

```typescript
const response = await fetch("https://next-flow-beta.vercel.app/api/v1/workflows", {
  headers: { "Authorization": "Bearer nf_YOUR_API_KEY" },
});
const { workflows } = await response.json();
```
