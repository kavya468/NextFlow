---
title: "Get Workflow"
openapi: "GET /v1/workflows/{id}"
description: "Retrieve complete structural details of a specific workflow, including its nodes and edges."
---

## Authentication

Requires a Bearer token in the `Authorization` header.

## Path Parameters

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `id`      | string| Yes      | The unique identifier of the workflow. |

## Response

Returns the full structure of the workflow including `nodes` and `edges`.

### Example Usage

```bash
curl -X GET "https://next-flow-beta.vercel.app/api/v1/workflows/123e4567-e89b-12d3-a456-426614174000" \
  -H "Authorization: Bearer nf_YOUR_API_KEY"
```

```typescript
const response = await fetch("https://next-flow-beta.vercel.app/api/v1/workflows/123e4567-e89b-12d3-a456-426614174000", {
  headers: { "Authorization": "Bearer nf_YOUR_API_KEY" },
});
const workflow = await response.json();
```
