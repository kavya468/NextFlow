title: "Quickstart"
description: "Start generating content programmatically in minutes"
---

Follow these steps to trigger your first NextFlow workflow from the API.

### Step 1: Get an API key

Head to **Settings → API Keys** and click **Generate Key**.

### Step 2: List your workflows

Find the ID of the workflow you want to execute by calling the List Workflows endpoint.

```bash
curl -X GET "https://api.nextflow.app/v1/workflows" \
  -H "Authorization: Bearer nf_YOUR_API_KEY"
```

### Step 3: Execute a workflow

Once you have your workflow ID, execute it.

```bash
curl -X POST "https://api.nextflow.app/v1/workflows/123e4567-e89b-12d3.../execute" \
  -H "Authorization: Bearer nf_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {"node-id": {"prompt": "A futuristic city in cyberpunk style"}}}'
```

Using TypeScript `fetch`:

```typescript
const response = await fetch("https://api.nextflow.app/v1/workflows/123e4567.../execute", {
  method: "POST",
  headers: {
    "Authorization": "Bearer nf_YOUR_API_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    inputs: {
      "promptNode": { prompt: "A futuristic city in cyberpunk style" }
    }
  })
});
const data = await response.json();
console.log("Execution ID:", data.runId);
```

### Step 4: Poll execution status

The execute endpoint kicks off the pipeline asynchronously. You can use the returned `runId` to poll for its status.

```bash
curl -X GET "https://api.nextflow.app/v1/executions/{runId}" \
  -H "Authorization: Bearer nf_YOUR_API_KEY"
```
