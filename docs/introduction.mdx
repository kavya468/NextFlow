NextFlow is an advanced AI generation platform designed to let you build powerful image, video, and audio pipelines through a visual workflow builder and an intuitive API.

## What you can build with the API

The NextFlow API provides full programmatic access to all generation capabilities:

- **Image Pipelines**: Trigger multi-stage generation, enhancement, and outpainting logic.
- **Video Pipelines**: Automate FFmpeg rendering and video concatenation dynamically.
- **Audio & TTS**: Chain text-to-speech providers like ElevenLabs inside larger workflows.
