title: "Introduction"
description: "Build and run connected media workflows with NextFlow."
---

NextFlow connects text, image, audio, and video tools in a visual graph. Save a workflow in the editor, then use the API to supply runtime inputs, execute it, and inspect each step's result.

The API supports workflow discovery, full or selected-node execution, run status, and credit balance. The HTTP MCP endpoint also exposes graph editing tools. See the [repository README](https://github.com/kavya468/NextFlow) for local setup and current release limitations.

Paid execution reserves a maximum credit amount before dispatch. A failed dependency blocks its downstream steps; an uncertain provider result retains its credit hold for reconciliation.

Start with [authentication](/authentication), then follow the [quickstart](/quickstart). Examples describe the source in this repository; an older hosted deployment may expose a different contract.
